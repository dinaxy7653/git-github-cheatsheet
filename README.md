# Git og GitHub trygg arbeidsflyt

Et React- og Vite-basert cheat sheet for trygg arbeidsflyt med Git Bash, Visual Studio Code og GitHub.

## Kjør lokalt

```bash
npm install
npm run dev
```

Åpne adressen som vises i terminalen.

## Bygg prosjektet

```bash
npm run build
```

Den ferdige nettsiden blir lagt i mappen `dist`.

Se [TEKNIKKER.md](TEKNIKKER.md) for forklaring på fem avanserte teknikker som er brukt.
